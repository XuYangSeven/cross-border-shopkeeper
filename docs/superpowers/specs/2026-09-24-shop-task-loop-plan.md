# 店铺经营任务闭环实现计划

## 1. 扩展任务引擎

- 保留现有6项任务配置与业务口径。
- 增加实时状态、结算锁定状态、当前值、差距、建议和目标页面。
- 增加结算摘要、奖励计算、奖励已领取保护。
- 缺失数据返回“未开始”，不把缺失值当作达标。

## 2. 接入状态管理

- 在正式店铺状态增加任务结算、历史和奖励领取字段。
- 练习副本复制任务相关字段。
- 保存周结算时生成任务锁定结果。
- 正式模式写入历史并只领取一次奖励；练习模式只生成预览。
- 重置本周时重置任务周期字段，但保留章节进度。

## 3. 完善店铺首页

- 任务行可点击展开详情。
- 详情展示目标、当前值、差距、状态和建议。
- 增加“去处理”按钮并按配置跳转对应模块。
- 显示实时完成数、模式和奖励预览。

## 4. 完善结算页

- 展示6项任务锁定结果。
- 展示正式奖励或练习预览。
- 防止重复领取。
- 展示周复盘摘要和最近结算信息。

## 5. 测试与验证

- 扩展任务引擎测试：无数据、实时达标、结算锁定、奖励计算、目标跳转。
- 扩展状态测试：正式/练习隔离、历史写入、重复奖励保护。
- 运行店铺、任务、广告、库存、客服、资金、数据分析和29项利润回归测试。
- 运行全量JavaScript语法检查及WXML复杂表达式检查。
